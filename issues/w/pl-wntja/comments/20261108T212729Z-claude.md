Built on feature/issue-times. times.py derives created and updated times from one git log over the issues directory (author time), uncommitted or untracked files from their mtime, and mtimes alone without history. list and search take --sort rank|created|updated; with a time sort, --json adds created_at and updated_at (named apart from the header's created date). The board shows created and updated on each card, has a sort control, and with a time sort a drop changes only the status (move keep_rank). No caching: the board recomputes on each reload, which already happens only when the files change. web now reads git through times; ARCHITECTURE.md says so.
